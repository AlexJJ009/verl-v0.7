\section{方法：On-Policy Weak-Driven SFT}
\label{sec:method}

本节说明当前分支中使用的 \textbf{On-Policy Weak-Driven SFT}（WDL-SFT）算法族。该方法族的共同基础是：用 weak model 与 strong model 的 logits 构造一个 fused policy，在 fused policy 下进行 on-policy rollout，然后在 fused log-prob 上训练两个子模型。v1/v2 把 reward function 的二元判断直接解释为正向/反向 SFT 信号；当前新方法 v3 则把训练目标改写为 group-advantage policy-gradient surrogate，并为 all-correct group 保留正向 SFT fallback。

文档分为四部分：首先定义 logit fusion 与训练数据流；然后给出 v1、v2 与当前 v3 的损失函数；接着用 TikZ 给出 v3 训练流程图；最后在附录中记录实现迭代中遇到的问题，尤其是 advantage 语义修复和 dual-submodel rollout 的负面结果。本文暂不记录实验结果表，因为旧实验编号和 pre-fix/post-fix 状态容易混淆，后续应另写结果章节。

\subsection{方法动机}
\label{subsec:motivation}

设 weak model 参数为 $\theta_1$，strong model 参数为 $\theta_2$。二者在同一个上下文 $(x,y_{<t})$ 上分别输出 logits：
\begin{equation}
    z^{(1)}_t = z^{(1)}(x,y_{<t};\theta_1),
    \qquad
    z^{(2)}_t = z^{(2)}(x,y_{<t};\theta_2).
\end{equation}
给定融合系数 $\lambda\in[0,1]$，定义 fused logits 与 fused policy：
\begin{align}
    z^{\mathrm{mix}}_t
        &= (1-\lambda)z^{(1)}_t + \lambda z^{(2)}_t, \label{eq:mix_logit}\\
    \pi^{\mathrm{mix}}_\theta(\cdot\mid x,y_{<t})
        &= \mathrm{softmax}\!\left(z^{\mathrm{mix}}_t\right),
        \qquad \theta=(\theta_1,\theta_2). \label{eq:mix_policy}
\end{align}

WDL-SFT 希望利用 fused policy 产生比单独 weak model 更强、又不完全等同于 strong model 的训练轨迹。训练时 loss 只依赖 fused log-prob：
\begin{equation}
    \ell_{i,t}(\theta)
    = \log \pi^{\mathrm{mix}}_\theta
      \left(y^i_t\mid x,y^i_{<t}\right).
\end{equation}
由于 fused logits 对两个子模型是线性的，任意经过 $z^{\mathrm{mix}}$ 的 loss 都会按下面的方式把梯度分配到两个子模型：
\begin{align}
    \nabla_{\theta_1}\mathcal{L}
        &= (1-\lambda)J_1^\top g, \\
    \nabla_{\theta_2}\mathcal{L}
        &= \lambda J_2^\top g,
        \qquad
        g=\frac{\partial\mathcal{L}}{\partial z^{\mathrm{mix}}},
\end{align}
其中 $J_k=\partial z^{(k)}/\partial\theta_k$。因此两个子模型接收同一个 fused loss 的梯度方向，但梯度幅度由 $\lambda$ 控制。

\subsection{训练样本与 reward label}
\label{subsec:labels}

本小节先用单个 prompt 的 $N$ 条 rollout 写公式。这个写法最容易说明正负样本划分与 mask 机制；若 loss 输入 batch 恰好只包含一个 prompt group，它也与代码完全一致。实际代码中的 loss kernel 不接收 prompt id，而是对传入 actor loss 的整块 response batch 做统一归一化，见 \S\ref{subsec:batch_loss_impl}。

对一个 prompt $x$，从 rollout policy 采样 $N$ 条 response：
\begin{equation}
    y^1,\ldots,y^N \sim \mu_{\theta_{\mathrm{old}}}^{\mathrm{mix}}}(\cdot\mid x).
\end{equation}
在当前主方法中，rollout policy 与训练 policy 属于同一个 fused policy family：
\begin{equation}
    \mu_{\theta_{\mathrm{old}}}^{\mathrm{mix}}
    =
    \pi_{\theta_{\mathrm{old}}}^{\mathrm{mix}}.
\end{equation}
reward function 对每条 response 给出二元标签：
\begin{equation}
    r_i = R(x,y^i)\in\{+1,-1\}.
\end{equation}
正确集与错误集定义为
\begin{equation}
    \mathcal{C}=\{i:r_i=+1\},
    \qquad
    \mathcal{I}=\{i:r_i=-1\},
    \qquad
    k=|\mathcal{C}|.
\end{equation}
每条 response 的 token mask 记为 $m_{i,t}\in\{0,1\}$，其中真实 token 为 $1$，padding 为 $0$。

v1/v2 实现中有一个容易误解的工程细节：loss 函数从 \texttt{advantages[:, 0]} 读取 $r_i$，但这里的 \texttt{advantages} 不是 GRPO-centered advantage。训练器会在进入 WDL-SFT v1/v2 loss 前，把 raw reward label 写入 \texttt{advantages}，即每条 response 的 label 是 $+1$ 或 $-1$。这一步在 2026-04-27 已修复；修复前的 \texttt{wdl\_sft\_is} 会错误地从 GRPO-centered advantage 的符号推断 $\mathcal{C}/\mathcal{I}$，因此 pre-fix 结果不能当作当前 v2 的干净实现。v3 显式排除这条 raw-label override 路径，改为使用 GRPO outcome advantage 加 all-correct positive-SFT fallback。

\subsection{v1：朴素 WDL-SFT}
\label{subsec:v1}

v1 对正确轨迹做正向 SFT，对错误轨迹做反向 SFT。其 positive loss 为
\begin{equation}
    \mathcal{L}^{+}_{\mathrm{v1}}(x)
    =
    -\frac{1}{|\mathcal{C}|}
    \sum_{i\in\mathcal{C}}\sum_t
    m_{i,t}\,\ell_{i,t}(\theta).
    \label{eq:v1_pos}
\end{equation}
negative loss 为
\begin{equation}
    \mathcal{L}^{-}_{\mathrm{v1}}(x)
    =
    \frac{1}{|\mathcal{I}|}
    \sum_{i\in\mathcal{I}}\sum_t
    m_{i,t}\,\ell_{i,t}(\theta).
    \label{eq:v1_neg}
\end{equation}
总 loss 为
\begin{equation}
    \mathcal{L}_{\mathrm{v1}}(x)
    =
    \mathcal{L}^{+}_{\mathrm{v1}}(x)
    +
    \beta\,\mathcal{L}^{-}_{\mathrm{v1}}(x),
    \qquad
    \beta\ge 0.
    \label{eq:v1_total}
\end{equation}

式 \eqref{eq:v1_pos} 的负号表示提高正确 response 的 fused likelihood。式 \eqref{eq:v1_neg} 没有负号；由于 log-prob 通常为负，最小化 $\beta\mathcal{L}^{-}_{\mathrm{v1}}$ 会降低错误 response 的 fused likelihood。若 $|\mathcal{I}|=0$，则 $\mathcal{L}^{-}_{\mathrm{v1}}=0$。在历史 v1 实现中，若 $|\mathcal{C}|=0$，整个 prompt 会被跳过。

v1 的问题是它假设训练时的 $\pi_\theta^{\mathrm{mix}}$ 与 rollout 时的 $\pi_{\theta_{\mathrm{old}}}^{\mathrm{mix}}$ 足够一致。这个假设在两类场景下不成立：
\begin{enumerate}
    \item 一个 rollout batch 会被拆成多个 mini-batch 连续更新，后续 mini-batch 使用的是旧 policy 采样的 label 和新 policy 的 log-prob。
    \item rollout 使用 vLLM + FlashInfer，训练使用 FSDP + FlashAttention-2，即使参数相同，两边的 log-prob 也会有数值差异。
\end{enumerate}
v2 的目标就是补上这两类 on-policy 训练中常见的稳定性机制。

\subsection{v2：当前 IS 修正版 WDL-SFT}
\label{subsec:v2}

v2 保留 v1 的 $\mathcal{C}/\mathcal{I}$ 划分和正负 SFT 目标，但额外加入两类 token 级修正：
\begin{itemize}
    \item 用 \texttt{old\_log\_prob} 构造 policy staleness ratio，并用 binary mask 做 ratio clipping。
    \item 用 \texttt{rollout\_is\_weights} 修正 vLLM rollout 与 FSDP training 之间的 log-prob 数值差异。
\end{itemize}

记 old-policy log-prob 为
\begin{equation}
    \ell^{\mathrm{old}}_{i,t}
    =
    \log \pi^{\mathrm{mix}}_{\theta_{\mathrm{old}}}
    \left(y^i_t\mid x,y^i_{<t}\right).
\end{equation}
token 级 ratio 定义为
\begin{equation}
    \rho_{i,t}(\theta)
    =
    \exp\!\left(
        \mathrm{clip}\left(
            \ell_{i,t}(\theta)-\ell^{\mathrm{old}}_{i,t},
            -20,\,
            20
        \right)
    \right).
    \label{eq:ratio}
\end{equation}
设上界阈值为 $\epsilon_{\mathrm{high}}$，下界阈值为 $\epsilon_{\mathrm{low}}$。当前默认值为
\begin{equation}
    \epsilon_{\mathrm{low}}=0.2,
    \qquad
    \epsilon_{\mathrm{high}}=0.27.
\end{equation}

正样本 keep mask 直接写成分段函数：
\begin{equation}
    K^+_{i,t}
    =
    \begin{cases}
        1,
        & i\in\mathcal{C},\ m_{i,t}=1,\ \rho_{i,t}(\theta)\le 1+\epsilon_{\mathrm{high}},\\
        0,
        & \text{otherwise}.
    \end{cases}
    \label{eq:pos_mask}
\end{equation}
负样本 keep mask 为
\begin{equation}
    K^-_{i,t}
    =
    \begin{cases}
        1,
        & i\in\mathcal{I},\ m_{i,t}=1,\ \rho_{i,t}(\theta)\ge 1-\epsilon_{\mathrm{low}},\\
        0,
        & \text{otherwise}.
    \end{cases}
    \label{eq:neg_mask}
\end{equation}

这两个 mask 是 binary selector。被 mask 掉的 token 不参与 loss，也不回传梯度。它不是 PPO 的 min-clip surrogate：我们没有把 ratio 替换成 clipped ratio，而是直接把越界 token 的梯度置零。实现中 $K^+_{i,t}$、$K^-_{i,t}$ 和 \texttt{rollout\_is\_weights} 都 detach，梯度只经过当前 fused log-prob $\ell_{i,t}(\theta)$。

设 $w_{i,t}$ 为 \texttt{rollout\_is\_weights}。如果没有启用 rollout correction，则 $w_{i,t}=1$。v2 positive loss 为
\begin{equation}
    \mathcal{L}^{+}_{\mathrm{v2}}(x)
    =
    -\frac{1}{\max(|\mathcal{C}|,1)}
    \sum_i\sum_t
    K^+_{i,t}\,w_{i,t}\,\ell_{i,t}(\theta).
    \label{eq:v2_pos}
\end{equation}
v2 negative loss 为
\begin{equation}
    \mathcal{L}^{-}_{\mathrm{v2}}(x)
    =
    \frac{1}{\max(|\mathcal{I}|,1)}
    \sum_i\sum_t
    K^-_{i,t}\,w_{i,t}\,\ell_{i,t}(\theta).
    \label{eq:v2_neg}
\end{equation}
总 loss 为
\begin{equation}
    \mathcal{L}_{\mathrm{v2}}(x)
    =
    \mathcal{L}^{+}_{\mathrm{v2}}(x)
    +
    \beta\,\mathcal{L}^{-}_{\mathrm{v2}}(x).
    \label{eq:v2_total}
\end{equation}

v2 与 v1 的边界条件有一个重要差异：当 $|\mathcal{C}|=0$ 时，v2 不跳过整个 prompt，而是令 $\mathcal{L}^{+}_{\mathrm{v2}}=0$，并在 $\beta>0$ 时保留 $\mathcal{L}^{-}_{\mathrm{v2}}$。这使得全错 prompt 仍然可以提供反向 SFT 信号。

\subsection{代码中的 batch-level loss}
\label{subsec:batch_loss_impl}

当前实现中的 \texttt{compute\_wdl\_sft\_loss} 与 \texttt{compute\_wdl\_sft\_is\_loss} 不按 prompt id 分组。它们接收到的张量已经是若干条 response row 组成的 loss input batch。记这一批 response 为
\begin{equation}
    \mathcal{B}=\{1,\ldots,M\},
\end{equation}
其中每个 $a\in\mathcal{B}$ 表示一条 response，而不是一个 prompt。每条 response 有 label $r_a\in\{+1,-1\}$、token mask $m_{a,t}$、当前 fused log-prob $\ell_{a,t}(\theta)$，以及 v2 中的 old-policy log-prob $\ell^{\mathrm{old}}_{a,t}$。代码实际使用的正负集合为
\begin{equation}
    \mathcal{C}_{\mathcal{B}}=\{a\in\mathcal{B}:r_a>0\},
    \qquad
    \mathcal{I}_{\mathcal{B}}=\{a\in\mathcal{B}:r_a<0\}.
\end{equation}
因此归一化分母是当前 loss input batch 内的 correct/incorrect response 数，而不是每个 prompt 内部分别统计的数量。

v1 的代码形式先计算每条 response 的 sequence log-prob：
\begin{equation}
    s_a(\theta)=\sum_t m_{a,t}\,\ell_{a,t}(\theta).
\end{equation}
若 $\mathcal{C}_{\mathcal{B}}=\varnothing$，v1 直接返回零 loss。否则：
\begin{align}
    \mathcal{L}^{+}_{\mathrm{v1,batch}}
        &=
        -\frac{1}{|\mathcal{C}_{\mathcal{B}}|}
        \sum_{a\in\mathcal{C}_{\mathcal{B}}}
        s_a(\theta), \\
    \mathcal{L}^{-}_{\mathrm{v1,batch}}
        &=
        \begin{cases}
            \dfrac{1}{|\mathcal{I}_{\mathcal{B}}|}
            \sum_{a\in\mathcal{I}_{\mathcal{B}}}
            s_a(\theta),
            & |\mathcal{I}_{\mathcal{B}}|>0,\\
            0,
            & |\mathcal{I}_{\mathcal{B}}|=0,
        \end{cases} \\
    \mathcal{L}_{\mathrm{v1,batch}}
        &=
        \mathcal{L}^{+}_{\mathrm{v1,batch}}
        +
        \beta\,\mathcal{L}^{-}_{\mathrm{v1,batch}}.
\end{align}

v2 的代码形式同样在 batch level 上构造 ratio 与 mask：
\begin{equation}
    \rho_{a,t}(\theta)
    =
    \exp\!\left(
        \mathrm{clip}\left(
            \ell_{a,t}(\theta)-\ell^{\mathrm{old}}_{a,t},
            -20,\,
            20
        \right)
    \right).
\end{equation}
对应 keep mask 为
\begin{align}
    K^+_{a,t}
    &=
    \begin{cases}
        1,
        & a\in\mathcal{C}_{\mathcal{B}},\ m_{a,t}=1,\ \rho_{a,t}(\theta)\le 1+\epsilon_{\mathrm{high}},\\
        0,
        & \text{otherwise},
    \end{cases} \\
    K^-_{a,t}
    &=
    \begin{cases}
        1,
        & a\in\mathcal{I}_{\mathcal{B}},\ m_{a,t}=1,\ \rho_{a,t}(\theta)\ge 1-\epsilon_{\mathrm{low}},\\
        0,
        & \text{otherwise}.
    \end{cases}
\end{align}
设 $w_{a,t}$ 为 \texttt{rollout\_is\_weights}，未启用时等于 $1$。真实 v2 loss 为
\begin{align}
    \mathcal{L}^{+}_{\mathrm{v2,batch}}
        &=
        -\frac{
            \sum_{a\in\mathcal{B}}\sum_t
            K^+_{a,t}\,w_{a,t}\,\ell_{a,t}(\theta)
        }{
            \max(|\mathcal{C}_{\mathcal{B}}|,1)
        }, \\
    \mathcal{L}^{-}_{\mathrm{v2,batch}}
        &=
        \frac{
            \sum_{a\in\mathcal{B}}\sum_t
            K^-_{a,t}\,w_{a,t}\,\ell_{a,t}(\theta)
        }{
            \max(|\mathcal{I}_{\mathcal{B}}|,1)
        }, \\
    \mathcal{L}_{\mathrm{v2,batch}}
        &=
        \mathcal{L}^{+}_{\mathrm{v2,batch}}
        +
        \beta\,\mathcal{L}^{-}_{\mathrm{v2,batch}}.
\end{align}

这个 batch-level 形式和前面的 prompt-level 形式有相同的正负方向、ratio mask 与 rollout IS 机制；差异只在归一化粒度。代码是按 response 数归一化，不按 token 数归一化，也不在 loss kernel 内按 prompt group 单独归一化。因此长 response 的 sequence token-sum 会比短 response 对梯度有更大影响。

\subsection{v3：WDL group-advantage IS}
\label{subsec:v3}

v3 对应当前实现中的 \texttt{loss\_mode=wdl\_group\_adv\_is}。它保留 fused rollout 与 fused actor update 的数据路径，但不再把 raw reward label 当作正负 SFT selector。训练器先按 prompt \texttt{uid} 计算 group-level outcome advantage，然后把 all-correct group 的正向 SFT fallback 加进 \texttt{advantages}，最后 actor loss 把该系数与 old/current policy ratio 相乘。

对 prompt group $g$，设该 prompt 下的 rollout response 集合为
\begin{equation}
    \mathcal{G}_g=\{i:\mathrm{uid}(i)=g\}.
\end{equation}
每条 response 的 reward 为
\begin{equation}
    R_i\in\{+1,-1\}.
\end{equation}
v3 第一版固定使用 mean-centered group advantage，不做 std normalization：
\begin{equation}
    \texttt{algorithm.norm\_adv\_by\_std\_in\_grpo}=\texttt{false},
    \qquad
    A_i
    =
    R_i-\frac{1}{|\mathcal{G}(i)|}
    \sum_{j\in\mathcal{G}(i)}R_j.
    \label{eq:v3_group_adv}
\end{equation}
其中 $\mathcal{G}(i)$ 表示 response $i$ 所属的 prompt group。mixed group 中正确 response 的 $A_i>0$，错误 response 的 $A_i<0$；all-correct 与 all-incorrect group 的 $A_i$ 都为 $0$。

纯 group advantage 会让 all-correct group 没有梯度，但这类 group 在 WDL-SFT 中仍是有价值的正向 SFT 信号。因此 v3 加入 all-correct positive-SFT fallback：
\begin{equation}
    F_i =
    \begin{cases}
        1,
        & \text{if } R_j=+1 \text{ for all } j\in\mathcal{G}(i),\\
        0,
        & \text{otherwise},
    \end{cases}
    \qquad
    G_i = A_i + \gamma_{\mathrm{pos}}F_i.
    \label{eq:v3_effective_coeff}
\end{equation}
当前默认 $\gamma_{\mathrm{pos}}=1$。于是三类 prompt group 的行为为
\begin{equation}
    \begin{array}{c|c|c|c}
    \text{group type} & A_i & F_i & G_i \\
    \hline
    \text{all-correct} & 0 & 1 & +\gamma_{\mathrm{pos}} \\
    \text{all-incorrect} & 0 & 0 & 0 \\
    \text{mixed} & R_i-\overline{R}_{\mathcal{G}(i)} & 0 & A_i
    \end{array}
    \label{eq:v3_group_cases}
\end{equation}
因此 v3 不是纯 group-advantage 方法，也不是标准 GRPO：all-correct group 仍保留正向 SFT 更新；all-incorrect group 不更新；mixed group 由 group advantage 的正负号同时驱动正确与错误 response。

old/current policy ratio 仍然在 fused policy family 内定义。训练 batch 中的 old log-prob 为
\begin{equation}
    \ell^{\mathrm{old}}_{i,t}
    =
    \log \pi^{\mathrm{mix}}_{\theta_{\mathrm{old}}}
    \left(y^i_t\mid x_i,y^i_{<t}\right),
\end{equation}
当前 actor forward 得到
\begin{equation}
    \ell_{i,t}(\theta)
    =
    \log \pi^{\mathrm{mix}}_\theta
    \left(y^i_t\mid x_i,y^i_{<t}\right).
\end{equation}
token-level ratio 为
\begin{equation}
    \rho_{i,t}
    =
    \exp\!\left(
        \mathrm{clip}\left(
            \ell_{i,t}(\theta)-\ell^{\mathrm{old}}_{i,t},
            -20,\,
            20
        \right)
    \right).
    \label{eq:v3_ratio}
\end{equation}
这里的 ratio 是 $\pi^{\mathrm{mix}}_\theta/\pi^{\mathrm{mix}}_{\theta_{\mathrm{old}}}$，不是 model2-only policy 与 fused policy 之间的 ratio。

v3 沿用 MiniRL-style binary trust-region mask，但 mask 的方向由 effective coefficient $G_i$ 的符号决定：
\begin{equation}
    K_{i,t}
    =
    \begin{cases}
        1,
        & m_{i,t}=1,\ G_i\ge 0,\ \rho_{i,t}\le 1+\epsilon_{\mathrm{high}},\\
        1,
        & m_{i,t}=1,\ G_i<0,\ \rho_{i,t}\ge 1-\epsilon_{\mathrm{low}},\\
        0,
        & \text{otherwise}.
    \end{cases}
    \label{eq:v3_keep_mask}
\end{equation}
mask 只做 token keep/drop，不是 PPO/GRPO 的 min-clipped surrogate。

v3 的 token loss 为
\begin{equation}
    q_{i,t}(\theta)
    =
    -\mathrm{sg}(G_i)\,
     \mathrm{sg}(\rho_{i,t})\,
     \mathrm{sg}(K_{i,t})\,
     \ell_{i,t}(\theta),
    \label{eq:v3_token_loss}
\end{equation}
其中 $\mathrm{sg}(\cdot)$ 表示 stop-gradient。也就是说，梯度只经过当前 fused log-prob：
\begin{equation}
    \nabla_\theta q_{i,t}
    =
    -\mathrm{sg}(G_i)\,
     \mathrm{sg}(\rho_{i,t})\,
     \mathrm{sg}(K_{i,t})\,
     \nabla_\theta \ell_{i,t}(\theta).
\end{equation}
被 binary mask 剪掉的 token 梯度为 $0$；没有被剪掉的 token 梯度会被 detached ratio $\rho_{i,t}$ 乘起来。

代码中的聚合语义是 \texttt{seq-mean-token-sum}：
\begin{equation}
    \mathcal{L}_{\mathrm{v3}}
    =
    \frac{1}{|\mathcal{B}|}
    \sum_{i\in\mathcal{B}}
    \sum_t
    m_{i,t}\,q_{i,t}(\theta).
    \label{eq:v3_total}
\end{equation}
它按 response 做 mean，response 内部按 token 做 sum，因此不做 token-mean 或 length normalization。实现中该标量通过共享的 \texttt{agg\_loss(..., loss\_agg\_mode="seq-mean-token-sum")} 产生，以保持 distributed batch 下的 loss scale 一致。

v3 与 v2 的关键差异可以概括为：
\begin{itemize}
    \item v2 使用 raw reward label 划分 $\mathcal{C}/\mathcal{I}$；v3 使用 group advantage 加 all-correct fallback 得到 $G_i$。
    \item v2 的 old/current ratio 只参与 binary keep mask，真正的 token weight 来自 \texttt{rollout\_is\_weights}；v3 显式把 detached $\rho_{i,t}$ 乘进 loss。
    \item v2 仍有 $\beta\mathcal{L}^{-}$；v3 不使用 $\beta$，负向更新来自 mixed group 中的 $G_i<0$。
    \item v3 禁用 \texttt{rollout\_is\_weights}、KL penalty、actor KL loss 和 token-level length normalization。
\end{itemize}

\subsection{算法伪代码}
\label{subsec:algorithm}

\begin{algorithm}[H]
\caption{On-Policy WDL-SFT v3 的一个训练步}
\label{alg:wdl_sft_v3}
\begin{algorithmic}[1]
\Require prompt batch $\{x_b\}_{b=1}^{B}$；模型参数 $\theta=(\theta_1,\theta_2)$；融合系数 $\lambda$；每 prompt rollout 数 $N$；fallback 系数 $\gamma_{\mathrm{pos}}$
\State 使用 $\theta_{\mathrm{old}}$ 构造 fused policy $\pi_{\theta_{\mathrm{old}}}^{\mathrm{mix}}$
\For{$b=1,\ldots,B$}
    \State 从 $\pi_{\theta_{\mathrm{old}}}^{\mathrm{mix}}(\cdot\mid x_b)$ 采样 $N$ 条 response
\EndFor
\State 用 reward function 得到每条 response 的 raw label $r_i\in\{+1,-1\}$
\State 按 prompt \texttt{uid} 计算 $A_i=R_i-\mathrm{mean}_{j\in\mathcal{G}(i)}R_j$，且不做 std normalization
\State 对 all-correct group 计算 $F_i$，并写入 effective coefficient $G_i=A_i+\gamma_{\mathrm{pos}}F_i$
\State 在训练引擎上重算 old-policy log-prob $\ell^{\mathrm{old}}_{i,t}$
\State 当前参数前向得到 $\ell_{i,t}(\theta)$
\State 按式 \eqref{eq:v3_ratio} 计算 $\rho_{i,t}$，按式 \eqref{eq:v3_keep_mask} 得到 binary keep mask $K_{i,t}$
\State 按式 \eqref{eq:v3_token_loss}--\eqref{eq:v3_total} 计算 $\mathcal{L}_{\mathrm{v3}}$
\State 反向传播并更新 $\theta_1,\theta_2$
\end{algorithmic}
\end{algorithm}

\section{附录：实现迭代中遇到的问题}
\label{app:wdl_sft_issues}

\subsection{Advantage 语义修复}
\label{app:advantage_fix}

当前 WDL-SFT v2 的正负样本划分必须来自 raw reward label：
\begin{equation}
    r_i=+1 \Rightarrow i\in\mathcal{C},
    \qquad
    r_i=-1 \Rightarrow i\in\mathcal{I}.
\end{equation}
这里的 $r_i$ 不是 group-normalized advantage，也不是从 GRPO advantage 的符号推断出来的 label。

修复前，\texttt{wdl\_sft\_is} 没有像 \texttt{wdl\_sft} 一样把 raw reward label 写入 \texttt{advantages}，导致 loss 读取到的是 GRPO-centered advantage。这个 bug 在 mixed group 中可能不明显，因为正确样本与错误样本的符号通常还保持一致；但在 all-correct 和 all-incorrect group 中会直接出错：
\begin{itemize}
    \item all-correct group 的 centered advantage 全为 $0$，本应产生的正向 SFT 信号会被跳过。
    \item all-incorrect group 的 centered advantage 全为 $0$，当 $\beta>0$ 时本应产生的反向 SFT 信号会被跳过。
\end{itemize}

该问题已在 2026-04-27 修复：训练器会对 \texttt{loss\_mode in \{wdl\_sft, wdl\_sft\_is\}} 都应用 raw reward-label override。后续写实验结果时必须区分 pre-fix \texttt{wdl\_sft\_is} 与 post-fix spec-correct \texttt{wdl\_sft\_is}，不能把旧结果直接归因到当前公式。

\subsection{Dual-submodel rollout 的负面结果}
\label{app:dual_rollout_failure}

后续分支实现过一个来自导师建议的 dual-submodel rollout idea：分别从 model1 与 model2 采样，然后选择 model2-only rollout 作为训练数据，再用 fused joint policy 做训练。这个分支的实现完成了预期的数据流，但第一次真实 3A 训练暴露出方法层面的 off-policy 问题。

\subsubsection{新分支中的实际 loss}
\label{app:dual_rollout_loss}

记进入训练的 selected batch 为
\begin{equation}
    \mathcal{B}_2=\{a:y^a\sim\pi^{(2)}(\cdot\mid x^a)\}.
\end{equation}
这里的下标 $2$ 表示这些 response 来自 \texttt{sub\_model\_1}/model2。model1 也生成了 rollout，但不进入 $\mathcal{B}_2$。reward function 给出 raw label：
\begin{equation}
    r_a\in\{+1,-1\},
    \qquad
    \mathcal{C}_2=\{a\in\mathcal{B}_2:r_a>0\},
    \qquad
    \mathcal{I}_2=\{a\in\mathcal{B}_2:r_a<0\}.
\end{equation}

训练器随后用 fused policy 重新计算 old log-prob，并在 actor update 时计算当前 fused log-prob：
\begin{align}
    \ell^{\mathrm{old}}_{a,t}
        &=
        \log \pi^{\mathrm{mix}}_{\theta_{\mathrm{old}}}
        (y^a_t\mid x^a,y^a_{<t}),\\
    \ell_{a,t}(\theta)
        &=
        \log \pi^{\mathrm{mix}}_{\theta}
        (y^a_t\mid x^a,y^a_{<t}).
\end{align}
注意，二者都是 fused policy 的 log-prob；它们不是 model2 rollout policy 的 log-prob。ratio mask 因此只约束 fused old policy 到 fused current policy 的局部更新：
\begin{equation}
    \rho_{a,t}(\theta)
    =
    \exp\!\left(
        \mathrm{clip}
        \left(
            \ell_{a,t}(\theta)-\ell^{\mathrm{old}}_{a,t},
            -20,\,
            20
        \right)
    \right).
\end{equation}

keep mask 与主线 v2 相同：
\begin{align}
    K^+_{a,t}
    &=
    \begin{cases}
        1,
        & a\in\mathcal{C}_2,\ m_{a,t}=1,\ \rho_{a,t}(\theta)\le 1+\epsilon_{\mathrm{high}},\\
        0,
        & \text{otherwise},
    \end{cases}\\
    K^-_{a,t}
    &=
    \begin{cases}
        1,
        & a\in\mathcal{I}_2,\ m_{a,t}=1,\ \rho_{a,t}(\theta)\ge 1-\epsilon_{\mathrm{low}},\\
        0,
        & \text{otherwise}.
    \end{cases}
\end{align}

3A 脚本默认 \texttt{algorithm.rollout\_correction.rollout\_is=null}。同时，dual rollout trainer path 在启用 dual 模式时会移除 \texttt{rollout\_is\_weights}，并记录 \texttt{dual\_rollout/rollout\_is\_loss\_weight\_applied=0}。因此 3A 的实际 loss 中可以取 $w_{a,t}=1$：
\begin{align}
    \mathcal{L}^{+}_{\mathrm{3A}}
        &=
        -\frac{
            \sum_{a\in\mathcal{B}_2}\sum_t
            K^+_{a,t}\,\ell_{a,t}(\theta)
        }{
            \max(|\mathcal{C}_2|,1)
        },\\
    \mathcal{L}^{-}_{\mathrm{3A}}
        &=
        \frac{
            \sum_{a\in\mathcal{B}_2}\sum_t
            K^-_{a,t}\,\ell_{a,t}(\theta)
        }{
            \max(|\mathcal{I}_2|,1)
        },\\
    \mathcal{L}_{\mathrm{3A}}
        &=
        \mathcal{L}^{+}_{\mathrm{3A}}
        +
        \beta\,\mathcal{L}^{-}_{\mathrm{3A}}.
\end{align}
对于 3A，$\beta=0$，所以实际参与优化的是
\begin{equation}
    \mathcal{L}_{\mathrm{3A}}
    =
    \mathcal{L}^{+}_{\mathrm{3A}}.
\end{equation}

这个 loss 的形式仍然是 WDL-SFT-IS 的 sequence token-sum loss，但它被应用在 model2-generated tokens 上。ratio mask 比较的是 fused current policy 与 fused old policy，不会修正下面这个核心分布差异：
\begin{equation}
    y\sim\pi^{(2)}
    \quad\text{vs.}\quad
    \ell(\theta)=\log\pi^{\mathrm{mix}}_{\theta}(y).
\end{equation}

\subsubsection{为什么该流程不是 on-policy 主方法}
\label{app:dual_rollout_not_on_policy}

原始 on-policy WDL-SFT 的关键对齐关系是
\begin{equation}
    y\sim\pi^{\mathrm{mix}},
    \qquad
    \text{train with } \log\pi^{\mathrm{mix}}(y\mid x).
\end{equation}
dual-submodel 3A 的实际关系变成了
\begin{equation}
    y\sim\pi^{(2)},
    \qquad
    \text{train with } \log\pi^{\mathrm{mix}}(y\mid x).
\end{equation}
这不再是 on-policy WDL-SFT，而是 model2-to-fused 的 off-policy distillation。

该 mismatch 在自回归生成中比单步分类更严重。令 $y=(y_1,\ldots,y_T)$，则
\begin{equation}
    \frac{\pi^{\mathrm{mix}}(y\mid x)}{\pi^{(2)}(y\mid x)}
    =
    \prod_{t=1}^{T}
    \frac{
        \pi^{\mathrm{mix}}(y_t\mid x,y_{<t})
    }{
        \pi^{(2)}(y_t\mid x,y_{<t})
    }.
\end{equation}
数学题的 response 往往很长，几千个 token 上的中等 per-token disagreement 会累积成高方差的 sequence-level mismatch。model2 生成的 prefix 对 model2 来说可能自然，但 model1 没有生成这些 prefix；训练时 fused logits 又混入 model1，因此 fused log-prob 可能显著低于 model2 log-prob。loss 会迫使 fused policy 模仿这些 model2-only 长轨迹，进而产生很大的梯度。
