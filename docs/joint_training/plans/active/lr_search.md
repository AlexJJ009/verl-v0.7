# Learning Rate Hyperparameter Search

- Status: **ACTIVE**
- Branch: `feature/on-policy-wdl-sft`
- Created: 2026-04-16
- Prerequisite: M5.5 baseline (forward-only, lr=5e-7, 300 steps, stable)

---

## Motivation

M5.5 established that forward-only On-Policy WDL-SFT (beta=0) is stable at lr=5e-7. However, this LR was chosen conservatively (halved from M5's 1e-6 which was unstable with reverse SFT). Now that reverse SFT is permanently dropped, the optimal LR may differ.

Our method is **on-policy** (data generated by the model itself each step) and uses an **SFT loss** (cross-entropy on correct rollouts). This places it in a unique position:

- **Standard SFT** on static data typically uses lr=1e-5 to 5e-5 (high, because labels are fixed and training is teacher-forced)
- **Standard RL** (PPO/GRPO) typically uses lr=1e-6 to 5e-6 (low, because policy gradient is noisy)
- **On-Policy SFT** should be somewhere in between: the loss is SFT-style (stable gradients) but data shifts each step (requires lower LR than static SFT)

Expected optimal range: **1e-7 to 5e-6**

## Search Grid

| Run ID | Learning Rate | Steps | Status | Notes |
|--------|--------------|-------|--------|-------|
| M5.5 (baseline) | 5e-7 | 300 | DONE | Stable, checkpoints available |
| LR-1 | 1e-7 | 300 | PLANNED | Lower bound — may underfit |
| LR-2 | 2e-7 | 300 | PLANNED | Conservative |
| LR-3 | 1e-6 | 300 | PLANNED | M5 LR but without reverse SFT — should be stable now |
| LR-4 | 2e-6 | 300 | PLANNED | Aggressive |
| LR-5 | 5e-6 | 300 | PLANNED | Upper bound — may diverge |

All runs keep identical config except LR:
- beta=0.0 (forward-only)
- lambda=0.5
- N=8 rollouts, B=64 prompts
- grad_clip=500.0, weight_decay=0.1, warmup=5 steps
- save_freq=25, test_freq=25

## Evaluation Criteria

1. **Stability**: Does the run complete 300 steps without divergence?
2. **Validation accuracy**: MATH-500 acc/mean@1 and AIME-2025 acc/mean@1 at best checkpoint
3. **Loss trajectory**: Smooth downward trend in wdl_sft_loss_positive
4. **Reward trajectory**: Upward trend in critic/score/mean
5. **Entropy**: Should decrease gradually, not collapse

## Implementation

Each LR run uses the M5.5 script as base, overriding only the LR:

```bash
# Example: run LR-3 (1e-6)
tmux new-session -s lr3
bash recipe/on_policy_wdl_sft/run_on_policy_wdl_sft_qwen3_4b_math_m5_5.sh \
    actor_rollout_ref.actor.optim.lr=1e-6 \
    RUN_PREFIX=WDL-SFT-Qwen3-4B-MATH-LR3
```

After all runs complete, compare validation metrics across checkpoints to select the best LR for the full-length training run.
